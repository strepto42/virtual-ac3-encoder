Virtual AC3 Encoder Control Center - Quick Start

1. Build the project from source. From the repository root, run:
       .\build.ps1
   See docs\BUILDING.md for prerequisites and dependency options.

2. Install and configure a virtual audio input such as VB-CABLE (https://vb-audio.com/Cable/),
   unless you use the optional virtual driver. For multichannel modes, configure the Windows
   playback endpoint as 5.1 and choose its corresponding capture endpoint in the control panel.

3. Start one of the control panels:
       .\bin\ControlCenter_A_Mixer.exe
       .\bin\ControlCenter_B_Modes.exe
   Select the capture device, digital output, and AC-3, DTS, or PCM mode, then start the engine.

4. For AC-3 or DTS over optical, use an S/PDIF output that accepts compressed passthrough and
   connect it to the receiver. The receiver should lock to Dolby Digital or DTS. PCM Stereo
   sends ordinary two-channel PCM.

DSP Studio is available from either Qt control panel or as:
       .\bin\VirtualAc3-DSP-Studio.exe

Useful engine commands:
       .\bin\engine.exe --list
       .\bin\engine.exe --probe

See docs\QUICKSTART.md for mode descriptions and command-line examples. See docs\ARCHITECTURE.md
for the audio path and component overview. The optional test-signed driver may require test-signing
mode and compatible Secure Boot settings; consult docs\BUILDING.md and scripts before installing it.
